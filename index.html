模拟自行车队经理

一款公路自行车队经理游戏的完整技术底座。逐秒物理引擎、集团动力学、 赛季推演与转会市场，13670 行纯 Python 标准库实现。

接手一支车队，定打法，逐场比赛跑下去，处理弹出来的俱乐部事务，赛季结束后签人、 集训，进入下一年。引擎不依赖任何第三方库，Unity / Godot / Web 前端都能把它当作 数值服务调用。

可以直接打开看的

比赛回放原型 一场山地赛的逐秒重演——集团怎么散、突围什么时候被追回 生涯回放 一名车手十个赛季的成长、巅峰与退役 历史档案 空跑 25 个赛季之后的名人堂、纪录与平衡诊断 赛道编辑器 画海拔剖面，即时看到坡度分级与赛道定性 赛历编辑器 编排一个赛季的赛事密度与类型分布

这些是把 Python 算好的结果冻进页面里的静态原型—— 能看，不能玩。要真的玩，游戏逻辑必须在你点下按钮之后运行，见下。

真的玩一局

git clone https://github.com/Lynch715/cycling-team-manager.git
cd cycling-team-manager
python3 source/play.py

需要 Python 3.10+，不装任何依赖。浏览器会自己打开，服务端只监听 127.0.0.1——它是一个单机游戏的壳，不是一个 web 服务。美术资源另外 640 MB，在 Releases 里下载；不下载也能玩，只是界面缺图。
